07 / Data

Choose your synchronization strategy.

A

Direct Remote

Writes directly to the server and updates the local cache after a successful response. Recommended for standard CRUD applications. Active by default.

B

Offline-Only

Stores data exclusively in local SQLite/Drift. Useful when remote synchronization is not required.

C

Outbox Sync

Writes immediately to local Drift, updates the UI optimistically, queues a synchronization task, and processes it in the background when connectivity returns.

How to switch strategies: there's no config flag — edit updateCounter() in counter_repository_impl.dart. Strategy A is the live code block; Strategy C sits directly below it, commented out. Comment out A and uncomment C to switch. Strategy B means skipping the remote datasource call entirely and writing to _localDatasource only.
