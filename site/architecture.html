03 / Architecture

Separation that scales.

Presentation UI · Controllers
→
Domain Entities · Contracts
→
Data Repositories · Sources
→
Infrastructure REST · Firebase · Drift
🔒

The business logic layer (Domain) doesn't depend on any tool. It never talks to Drift, Dio, or Firestore directly — only the Data layer does that. This means you can test your business rules without needing a real database or an internet connection.
