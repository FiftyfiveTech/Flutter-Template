05 / Installation

Get started in minutes.

STEP 01

Clone the template

Clone this repository (or use it as a template) and open the project root in your editor.

git clone <repo-url> your_app
STEP 02

Generate platforms

Creates the Android, iOS, Web, and other platform folders needed to actually run the app.

flutter create .
STEP 03

Rename the package

Change the default project name to your own, both in the code and in the Android/iOS app settings.

flutter_app_template → your_app
STEP 04

Install dependencies

Downloads all the packages this project needs.

flutter pub get
STEP 05

Generate code

Creates the auto-generated files needed by the database (Drift) and state management (Riverpod).

dart run build_runner build --delete-conflicting-outputs
STEP 06

Configure Firebase

Only required when using the Firestore datasource.

flutterfire configure
STEP 07

Run the app

Starts the app on your emulator, simulator, or a connected device.

flutter run
