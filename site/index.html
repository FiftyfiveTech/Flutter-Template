Clean Architecture

Every feature is split into three clear layers — UI, business logic, and data — so a change in one doesn't break the others.

⚡

Riverpod

Manages the app's state and shares data between screens in a predictable, easy-to-follow way.

💾

Drift Database

Stores data on the device itself, so the app stays fast and keeps working even without internet.

🌐

REST + Firebase

Use a REST API or Firebase for your server — you can switch between them without changing your app's core logic.

🔄

Sync Queue

An optional feature that saves changes on the device first, then sends them to the server once you're back online.

🤖

AI-Assisted

Ready-made instructions that let an AI assistant build features, data models, screens, and tests for you.
