08 / Reference

Skills your AI assistant can use.

docs/ai_workflow.md — Skills & Superpowers
💡

A "skill" is just a saved checklist your AI assistant follows automatically for certain tasks — so you don't have to repeat the same instructions every time.

Included in this template

SkillWhat it does
flutter-feature-scaffoldCreates all the standard files for a new feature (data model, repository, business logic, UI) in one go.
api-data-syncSets up the connection to Firestore or a REST API, plus the offline-sync queue, the same way every time.
riverpod-state-managementHelps write state-management code (loading/error states, tests) using this project's conventions.
flutter-ui-design-systemKeeps screens using the shared design values, and flags any hardcoded color/spacing/font.
flutter-overflow-auditChecks that forms and pop-ups still look right when the on-screen keyboard opens.
flutter-testingWrites the right kind of test (unit, widget, etc.) for whatever code you're testing.
CommandWhat it does
/new-feature <name>Creates the empty folder structure for a new feature.
/create-screen <name>Creates a new screen using the shared design values.
/create-provider <name>Creates a new Riverpod provider (a piece of app state).
/create-model <name>Creates a new data model.
/connect-api <name>Connects a feature to a REST API or Firestore.
/generate-tests <target>Writes tests for a specific file.
/refactor-widget <target>Pulls a widget out into its own file, in the right place.
/review-codeChecks a change against this project's rules.
/dod-checkChecks a feature against the "Definition of Done" checklist before you call it finished.
/audit-architectureScans the whole project for rule-breaking or messy structure.

Already built into Claude Code — nothing to install

These come with Claude Code itself. If you're using Claude Code, they already work — there's no setup needed for this template.

SkillWhy it's useful
security-reviewChecks your code for security issues before you merge it — cheap insurance for any app that handles user data.
code-review / simplifyA second pair of eyes to catch bugs or code that's more complicated than it needs to be.
datavizIf your app has charts or graphs, this keeps them looking consistent instead of styled one-off each time.
fewer-permission-promptsOnce things settle down, this stops asking you to approve the same safe commands over and over.
loopLets you schedule the Step 8 code check to run automatically instead of remembering to run it yourself.

Not built yet — write these if your project needs them

Unlike the tables above, these don't exist yet, in Claude Code or in this repo. They're good candidates for your own .claude/skills/[name]/SKILL.md file once your project actually needs them (see Prompt 6 on the Workflow page).

SkillWhy it's useful
a11y-complianceChecks things like screen-reader labels, color contrast, and tap-target size — the layout skill above doesn't cover this.
performance-auditLooks for things that slow the app down or cause memory leaks, once you have enough screens for that to matter.
l10n (if you support multiple languages)Keeps translated text organized in one standard format instead of scattered strings.
A rules-specific skill for your industry (if needed)If your app has legal or safety rules to follow (health, finance, etc.), turn those rules into a skill instead of relying on memory.
➕

Want to add a new skill? Create a file at .claude/skills/[skill-name]/SKILL.md describing what to check and when it should run. Then add a line about it to CLAUDE.md so it's easy to find later.
