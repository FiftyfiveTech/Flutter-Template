03 / Architecture

Separation that scales.

Presentation UI · Controllers
→
Domain Entities · Contracts
→
Data Repositories · Sources
→
Infrastructure REST · Firebase · Drift
🔒

Domain has zero framework dependencies. Entities, repository interfaces, and use cases never import Drift, Dio, or Firestore directly — only the Data layer does, which is what makes use cases unit-testable without a database or network.
